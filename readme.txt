Trabalho Prático da disciplina CCF 211 - Algoritmos e Estrutura de Dados desenvolvido em dupla com Gabriel Alves.

O principal objetivo do trabalho era utilizar a estrutura de dados LISTA ENCADEADA para representar uma lista linear de Pokémon na memória.
O tipo de lista linear escolhida foi a pilha.

Como compilar o projeto no linux com Cmake:
1. Coloque o arquivo de teste na pasta build com o nome "teste1.txt"
2. Abra o terminal na pasta build.
3. Cole os seguintes códigos, na ordem em que aparecem:
cmake ..
cmake --build .
4. Cole o código de execução a seguir:
./programa
